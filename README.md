# BMI Calculator

## Overview

The BMI Calculator is a simple web application built with Flask that calculates your Body Mass Index (BMI) from your height and weight and shows the result with its health category.

## Features

* Enter your height and weight to calculate your BMI.
* Displays the BMI value along with its category — Underweight, Normal, Overweight or Obese.
* Clean and simple web interface using HTML templates.

## Tech Stack

* Python — Programming language
* Flask — Web framework
* HTML/CSS — Frontend templates
* Jupyter Notebook — Project documentation and experimentation

## How to Run

1. Clone the repository:

   git clone https://github.com/Suraj881711/bmi-calculator.git

2. Install dependencies:

   pip install -r requirements.txt

3. Run the app:

   python bmi_app.py

4. Open your browser and go to:

   http://127.0.0.1:5000
